Choreo device check

Checks whether this Chromebook can play, read and store iPhone rehearsal videos. Nothing is uploaded anywhere — everything stays on this computer and is deleted afterwards.

1. Pick one or more rehearsal clips

Best: one clip filmed with the iPhone's normal settings, and one filmed with Settings → Camera → Formats → Most Compatible. Move them to the Chromebook the way you normally would.

2. Storage test

Writes a 300 MB test file, reads it back, then deletes it. Takes up to a minute.

3. Send the results

Copy this and send it back, so the app can be set up for this Chromebook.
